# DomainPcInfo — выпуск новой версии

Все команды ниже выполняются из корня локального клона репозитория.

## 1. Получить последние изменения

```powershell
git pull --ff-only
```

## 2. Проверить локальную сборку

```powershell
.\scripts\build-msi.ps1
```

## 3. Сохранить изменения

```powershell
git status
git add .
git commit -m "Описание изменений"
git push
```

## 4. Создать тег версии

Пример:

```powershell
git tag v1.0.1
git push origin v1.0.1
```

Формат тега:

```text
vX.Y.Z
```

После отправки тега GitHub Actions автоматически:

- собирает приложение;
- собирает MSI;
- берёт версию из тега;
- создаёт GitHub Release;
- прикладывает MSI к Release.

## Важно

- тег создаётся после отправки нужного commit в `main`;
- опубликованный тег не переносить на другой commit;
- старые теги не переиспользовать;
- для каждой новой версии увеличивать номер.
