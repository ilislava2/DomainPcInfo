DomainPcInfo
============

ДЛЯ ЧЕГО
--------

DomainPcInfo — небольшой информационный виджет для Windows.

Показывает:
- имя компьютера;
- домен или рабочую группу;
- текущий контроллер домена (DC);
- доступность DC по Ping;
- активные физические сетевые интерфейсы;
- IPv4-адреса физических интерфейсов.

Информация обновляется:
- при запуске;
- автоматически каждые 5 минут;
- вручную кнопкой обновления.

Если ПК не состоит в домене, отображается рабочая группа,
а "Доступ DC" показывает "Недоступно".


СТРУКТУРА
---------

Рабочий каталог:

D:\DomainPcInfo

Резервный/финальный каталог:

E:\04_Хобби\Программирование\DomainPcInfo

Основные каталоги:

src\DomainPcInfo
    Исходный код приложения.

installer\DomainPcInfo.Setup
    Проект MSI-установщика WiX.

scripts
    Скрипты запуска, публикации и сборки.

.github\workflows
    Автоматическая сборка через GitHub Actions.

artifacts\publish
    Файлы публикации приложения.

Основные файлы:

MainWindow.xaml
    Внешний вид виджета.

MainWindow.xaml.cs
    Обновление информации, таймер и положение окна.

SystemInfo.cs
    Имя ПК, домен и рабочая группа.

DomainInfo.cs
    Определение и проверка DC.

NetworkInfo.cs
    Физические сетевые интерфейсы и IPv4.

AppLog.cs
    Заглушка логирования.

Package.wxs
    Настройки MSI и автозапуска.

build-msi.ps1
    Сборка готового MSI.


УСТАНОВКА
---------

Для сборки нужен .NET 10 SDK.

Проверка:

dotnet --list-sdks

Сборка MSI:

cd D:\DomainPcInfo
.\scripts\build-msi.ps1

Готовый MSI находится примерно здесь:

D:\DomainPcInfo\installer\DomainPcInfo.Setup\bin\Release\DomainPcInfo-x64-1.0.0.msi

Локальная установка:

msiexec /i "D:\DomainPcInfo\installer\DomainPcInfo.Setup\bin\Release\DomainPcInfo-x64-1.0.0.msi"

Программа устанавливается в:

C:\Program Files\DomainPcInfo\

Автозапуск:

HKLM\Software\Microsoft\Windows\CurrentVersion\Run
DomainPcInfo


УСТАНОВКА ЧЕРЕЗ GPO
-------------------

Скопировать MSI в сетевой каталог, например:

\\SERVER\Software\DomainPcInfo\DomainPcInfo-x64-1.0.0.msi

В Group Policy Management:

Computer Configuration
→ Policies
→ Software Settings
→ Software installation
→ New
→ Package

Указать UNC-путь к MSI.

Выбрать:

Assigned

На тестовом клиенте:

gpupdate /force

Для установки через Computer Configuration обычно требуется перезагрузка ПК.


ЗАПУСК
------

Из исходников:

cd D:\DomainPcInfo
dotnet run --project .\src\DomainPcInfo\DomainPcInfo.csproj

Установленная версия:

& "C:\Program Files\DomainPcInfo\DomainPcInfo.exe"

После установки MSI программа автоматически запускается
при входе пользователя в Windows.


ОСТАНОВКА
---------

Если приложение запущено через dotnet run:

Ctrl + C

Остановить установленную версию:

Get-Process DomainPcInfo -ErrorAction SilentlyContinue | Stop-Process

Принудительно:

Get-Process DomainPcInfo -ErrorAction SilentlyContinue | Stop-Process -Force


УДАЛЕНИЕ
--------

Сначала остановить приложение:

Get-Process DomainPcInfo -ErrorAction SilentlyContinue | Stop-Process -Force

Удаление через MSI:

msiexec /x "D:\DomainPcInfo\installer\DomainPcInfo.Setup\bin\Release\DomainPcInfo-x64-1.0.0.msi"

Также можно удалить через:

Параметры Windows
→ Приложения
→ Установленные приложения
→ DomainPcInfo
→ Удалить

После удаления должны исчезнуть:

C:\Program Files\DomainPcInfo\

и запись автозапуска:

HKLM\Software\Microsoft\Windows\CurrentVersion\Run\DomainPcInfo
